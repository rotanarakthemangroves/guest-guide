APPROVED IMAGE ASSET WORKFLOW

This starter package includes the four venue photos used in the supplied Meal Plan Packages artwork, the original palm/sun/waves access icon, and the drinks-with-foliage image.

1. The included assets are in this folder and are referenced by relative paths such as ./assets/terra-restaurant.jpg.
2. To replace a default image, either replace the file in this folder while keeping its filename, or enter a guest-accessible image URL in the relevant Google Sheets image_url field.
3. For an external URL, verify it opens without staff sign-in in a private/incognito browser window.
4. The approved Rotana property logo is initially loaded from Rotana's image CDN. Its URL can be changed in Settings > logo_url.
5. Images are not embedded directly into a Google Sheets cell; the URL/path controls which image the website displays.
